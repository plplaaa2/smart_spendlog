자동 네트워크 백업

지정된 시간에 가계부 데이터를 JSON 백업 파일로 직렬화하여 지정된 네트워크 공유 디렉터리(UNC/Local) 또는 WebDAV 서버로 자동 백업합니다.

※ 개인 가계부 정보 보안을 위해 백업 파일은 서버 설정 토큰(token)을 기반으로 AES-256-CBC 암호화되어 전송됩니다.

⚠️ Home Assistant (HA) 환경 필수 주의사항:

[시스템 -> 스토리지]에서 추가/마운트한 공유 디렉터리의 로컬 마운트 경로(예: /share/backups, /media/backup, /backup 등)를 우선 지정하십시오. (UNC 경로 \\192.168.x.x\Backup는 Windows 단독 설치 환경에서만 지원됩니다.)

★ 중요: 설정을 변경하신 후 반드시 [설정 저장] 버튼을 누르거나 [테스트 실행]을 진행해 주시기 바랍니다. (테스트 실행 시 입력한 설정 정보가 먼저 자동 저장된 후 백업 전송 테스트가 진행됩니다.)

정규식 수동 작성 가이드

자동 수신된 문자에서 정보를 안전하게 분석하려면 패턴 내에 아래의 그룹 이름(?<이름>)이 반드시 매핑되어야 합니다.

(?<amount>[\d,]+) 금액 추출 (필수): 쉼표가 들어간 결제 금액을 파싱합니다.
(?<merchant>.+?) 사용처 추출: 돈을 사용한 가맹점명 또는 업종 정보를 파싱합니다. (예: 스타벅스, 이마트)
(?<time>\d{2}/\d{2}\s+\d{2}:\d{2}) 일시 추출: 결제 날짜와 시간대를 파싱합니다. (예: 05/22 14:30)
(?<account>[\d*-]+) 계좌번호 추출 (선택): 문자 내 계좌번호를 파싱하여 가계부 메모에 기록합니다.
(?<balance>[\d,]+) 잔액 추출 (선택): 거래 후 남은 잔액을 파싱하여 가계부 메모에 기록합니다.
(?<cumulative>[\d,]+) 누적금액 추출 (선택): 당월 누적 사용 금액을 파싱하여 가계부 메모에 기록합니다.
(?<usedPoint>[\d,]+) 차감 포인트 추출 (선택): 결제 시 사용/차감된 지원금 또는 카드 포인트를 파싱합니다.
(?<payMethod>[^\s/]+) 결제수단 추출 (선택): 금액이 빠져나가는 결제처(카드사, 은행명 등)를 파싱합니다. (예: KB국민, 신한카드)
(?<payType>[^\s/]+) 결제방식 추출 (선택): 결제 방법(신용, 체크, 이체, 현금 등)을 파싱합니다. (예: 신용, 체크)
유용한 정규식 문법 팁
  • 대괄호 앞에는 백슬래시 두 개를 써서 에스케이프 해줍니다. (예: \\[KB국민\\])
  • 임의의 텍스트 구간은 .* 또는 .*?로 넘깁니다.
  • 띄어쓰기(공백)는 \\s+(1개 이상) 또는 \\s*(0개 이상)를 대입합니다.

자동 패스규칙 편집

알림 텍스트가 이 정규식 패턴과 매칭되면 가계부에 등록되지 않고 즉시 PASS 처리됩니다.

패스 매칭 실시간 테스트기

패스 규칙 작성 가이드

알림 수신 시 가계부 등록을 생략하고 PASS 처리할 단어나 정규식 패턴을 지정합니다.

인증\s*번호|본인\s*확인 인증/보안 문자 패스: SMS 본인인증 문자를 무시합니다.
잔액\s*부족|한도\s*초과|승인\s*거절 잔액부족/거절 패스: 결제 실패나 거절 문자를 제외합니다.
\(광고\)|\[광고\] 광고 문자 패스: 스팸 및 광고성 메시지를 필터링합니다.
체결안내|분배금\s*입금|자동매수 투자/체결 알림 패스: 주식 체결 및 분배금 입금 등 금융 외 알림을 패스합니다.
고지서|명세서|이용요금\s*안내 안내/청구서 패스: 단순 카드대금 청구 안내 등을 제외합니다.
^[a-zA-Z0-9\.]+$ 패키지명 단독 패스: 내용 없이 앱 패키지명만 들어오는 알림을 필터링합니다.
패스 규칙 작성 팁

패스 정규식은 캡처그룹 (?<name>...)이 필요하지 않으며, 특정 단어의 포함 여부만으로 간단하게 작성할 수 있습니다. 다중 조건은 파이프라인(|) 기호로 연결합니다.
