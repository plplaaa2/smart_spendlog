# Changelog

본 문서는 Smart Spendlog 가계부 서비스의 공식 버전별 갱신 이력 및 변경 사항을 기록합니다.

## [Unreleased]

### 🐛 버그 수정 & 성능 개선 (Fixed)
*   **알림 중복 검사 안정화**: 결제방식 값을 중복 거래 검사 전에 확정하여 기존 거래가 조회될 때 선언 전 참조 오류로 알림 처리가 중단되는 문제 수정
*   **알림 재시도 데이터 보호**: 재파싱과 거래 정보 보정이 성공한 뒤에만 기존 거래를 교체하고, 삭제·삽입·로그 갱신을 하나의 트랜잭션으로 묶어 실패 시 기존 거래가 유지되도록 개선
*   **숫자형 거래일시 검증**: 8·12·14자리 숫자형 날짜에서 월별 말일과 시·분·초 범위를 검증하여 존재하지 않는 거래일시가 저장되지 않도록 개선
*   **일반 거래일시 검증**: 구분자·한글 날짜에도 실제 달력과 시간 범위 검증을 적용하고, 오전·오후 표시가 없는 12시가 00시로 변환되던 오류 수정
*   **포인트 캡처 그룹 호환성**: 기존 규칙의 `used_point`와 자동·AI 생성 규칙의 `usedPoint`를 모두 인식하여 포인트 사용액이 0으로 누락되지 않도록 개선
*   **파싱 규칙 순서 결정성**: 패스 규칙과 일반 규칙을 생성 순서(`id ASC`)로 조회하여 여러 규칙이 동시에 일치해도 항상 동일한 우선 규칙이 적용되도록 개선
*   **공통 파싱 결과 검증**: 정규식과 AI 파서 결과에 동일한 저장 계약을 적용하여 잘못된 금액·일시·거래 유형·결제방식·외화 정보가 거래 DB에 전달되지 않도록 개선
*   **AI 파싱 요청 안전성**: AI 알림 파싱에 30초 타임아웃과 64KB 응답 제한을 적용하고, 비 JSON 응답과 미지원 provider를 안전하게 거부하도록 개선
*   **AI 생성 규칙 검증**: AI 정규식의 길이·앵커·필수 그룹·중첩 수량자를 검사하고 원문 재파싱에 성공한 패턴만 캐시 규칙으로 저장하도록 강화
*   **로컬 자동 규칙 검증**: Webhook과 로그 재시도의 로컬 자동 생성 규칙에도 공통 정규식 안전성 검사와 원문 재파싱을 적용하여 검증된 규칙만 저장하도록 개선
*   **규칙 우선순위·활성화·출처 관리**: 규칙에 `priority`, `enabled`, `source` 메타데이터를 추가하고 DB·API·백업·파싱 조회·관리 화면에서 일관되게 관리하도록 개선
*   **규칙 DB 통합 테스트**: 실제 SQLite 메모리 DB에서 기존 `rules` 스키마 마이그레이션과 활성 규칙 우선순위 정렬을 검증하는 테스트 추가

## [2.5.0] - 2026-06-27

### 🚀 신규 기능 & UI 개선 (Added)
*   **안드로이드 상태표시줄 테마 연동**: 웹뷰 테마(다크/라이트) 변경 시 안드로이드 네이티브 상태표시줄의 배경색과 글자/아이콘 색상(라이트 테마 시 어두운 텍스트, 다크 테마 시 밝은 텍스트)이 실시간으로 동기화되어 가독성 개선
*   **안드로이드 초기 상태표시줄 스타일 보정**: 앱 기동 시 상태표시줄을 다크 테마(#0a0e1a 배경, 흰색 텍스트)로 초기화하여 초기 시인성 보장
*   **포인트 및 지원금 실적/지출 합산**: 카드 포인트나 지원금(`used_point`) 사용 시, 이를 당월 지출 및 카드 누적 실적 집계에 포함하여 실제 소비 규모가 통계에 정상 반영되도록 개선
*   **모바일 푸시 직접 연동**: 가계부 애드온 설정의 `ws_sensor_entity`에 등록된 기기 정보를 기반으로 Home Assistant 모바일 Companion 앱 서비스(`notify.mobile_app_<device>`) 및 공통 알림 서비스(`notify.notify`)를 직접 호출하여 스마트폰 알림센터에 푸시 알림이 기록으로 남도록 보강

### 🐛 버그 수정 & 성능 개선 (Fixed)
*   **Home Assistant 동기화 및 알림 정합성**: Home Assistant 센서 동기화 및 실적 달성 체크(`CARD_PERF`) 시 포인트 결제액 누락 현상 수정
*   **안드로이드 앱 동기화**: 안드로이드 WebView 앱 환경의 stats API 및 예산 감시/실적 알림 서비스에서도 포인트 사용분이 올바르게 지출에 합산되도록 정합성 교정
*   **안드로이드 알림센터 기록 유실**: 안드로이드 네이티브 앱에서 알림 발생 시 소형 아이콘 리소스를 호환되는 `R.mipmap.ic_launcher`로 교체하여 상단 상태바 및 시스템 알림센터에 정상 누적 및 보존되도록 버그 수정
*   **인앱 알림센터 기록 누락 및 실시간 동기화**: `SUPERVISOR_TOKEN` 검사를 리팩토링하여 단독 구동/로컬 개발 환경에서도 예산/실적 계산 및 인앱 알림(`inapp_notifications`)이 항상 생성되도록 보장하고, `NotificationsManager`를 전역 바인딩하여 거래 추가/수정/삭제 시 인앱 알림센터가 30초 대기 없이 실시간 즉시 갱신되도록 개선
*   **안드로이드 미디어 알림 성능 최적화**: 알림 리스너(`SpendLogListenerService`)에서 미디어 재생 알림(`MediaStyle`, `CATEGORY_TRANSPORT`)을 사전 필터링(Early Exit)하여, 라디오/음악 앱의 빈번한 재생 상태 갱신이 가계부 DB 쿼리 및 디스크 I/O를 반복 유발하던 문제를 해결하고 백그라운드 오디오 재생 시 소리 끊김 현상을 원천 차단
*   **설정·규칙 메뉴 하드코딩 색상 제거**: 설정 메뉴 및 규칙(정규식) 가이드 등에 남아있던 다크 테마 전용 rgba 색상값을 CSS 테마 변수로 교체하여 라이트 테마에서의 가독성 개선

## [2.3.0] - 2026-06-19

### 🚀 신규 기능 & UI 개선 (Added)
*   **대시보드 수입 0원 시 평균 수입 대체 표시**:
    *   당월 수입이 0원일 때 최근 6개월 중 수입이 실제 발생한(0원 초과) 달들의 평균 수입을 자동으로 계산하여 `(평균) XX,XXX원` 형태로 표시합니다.
    *   수입 카드 하단 푸터 영역에 `"이번 달 수입이 없어 월 평균 수입 표시"` 안내를 동적으로 제공하며, 수입이 1원이라도 발생하면 실제 수입 금액 및 기본 문구로 자동 전환됩니다.
*   **UI 테마 통합 및 가속화**:
    *   사용자 화면 테마를 다크(Dark) 및 라이트(Light) 2종으로 압축 및 정돈하여 직관성을 높였습니다.
    *   라이트 모드에서 가독성을 보장하기 위해 수신 로그 카드의 어두운 배경을 제거하고 CSS 테마 변수(`var(--glass-bg)`, `var(--glass-shadow)`)로 교체했습니다.
    *   화면 테마 변경 시 사이드바 배경 및 내부 시계 카드, 토글 버튼 그림자가 실시간으로 동기화되도록 반응형 CSS 및 JS를 정비했습니다.
*   **안드로이드 인앱 예산/실적 분석 및 실시간 알림 시스템**:
    *   안드로이드 전용 로컬 Room DB 및 `notifications` API 핸들러를 구축하여, 모바일 환경에서도 즉각적인 예산 실적 분석과 미분류 알림 상태 수신이 가능해졌습니다.

### 🐛 버그 수정 & 성능 개선 (Fixed)
*   **CSS 테마 변수 기반 Chart.js 색상 동적 연동**:
    *   대시보드 및 지출/수입 통계 차트 렌더링 시 격자선, 라벨 텍스트, 범례 색상을 하드코딩 대신 CSS 테마 변수(`var(--text-primary)`, `var(--glass-border)`)에서 실시간으로 읽어오도록 리팩토링하여 테마 전환 시 시인성을 확보했습니다.
*   **결제수단 강제 시딩(부활) 버그 수정**:
    *   사용자가 삭제한 결제수단(카드/계좌)이 애드온 재기동 시 기본 초기화 데이터에 의해 다시 생성되던 DB 시딩 논리적 모순을 해결했습니다. (최초 기동 시에만 시딩 동작 보장)
*   **API Rate Limit 임계치 상향**:
    *   자산 일괄 삭제 및 대규모 설정 변경 시 발생하는 API 요청 한도 초과(429 Too Many Requests) 및 UI 먹통 문제를 방지하기 위해 분당 요청 한도를 기존 60회에서 300회로 대폭 늘렸습니다.
*   **AI 리포트 마크다운 렌더러 정밀 보정**:
    *   기존 DB에 저장된 마크다운 리포트에서 다크모드용 흰색 글씨 색상이 하드코딩되어 라이트모드 진입 시 글자가 보이지 않던 문제를 해결하고자 CSS 테마 변수로 자동 보정 치환하는 동적 파서를 적용했습니다.

## [2.2.1] - 2026-06-15

### 🚀 신규 기능 & UI 개선 (Added)
*   **메인 헤더 반응형 2행 구조 개편**:
    *   기존 단일 행 구조에서 상단 행(글로벌 타이틀 및 알림/사용자 제어)과 하단 행(컨텍스트 정보 및 월간 선택기)으로 분할된 2행 레이아웃을 구현했습니다.
    *   월 선택기(`.month-picker`)가 대시보드 화면에서만 동적으로 노출되도록 렌더러와 탭 전환 이벤트를 보강했습니다.
    *   사이드바 하단 영역의 프로필 및 로그아웃 인터페이스를 헤더 상단의 우측 밀착 영역(`.header-right`)으로 배치 이관하여 공통 정합성을 확보했습니다.
*   **서브 탭 하이라이트 스타일 표준화**:
    *   소비 분석 서브 탭 등에서 존재하지 않는 스타일 변수(`--primary-color`) 사용으로 액티브 하이라이트가 누락되던 버그를 `var(--accent-color)` 공통 변수로 치환 및 인라인 스타일을 배제하여 통일성 있게 표준화했습니다.
    *   '은행별 입출금'을 '은행 입출금'으로, '일반지출 분석/고정지출 분석'을 '일반지출/고정지출'로 서브탭 레이블을 직관적으로 개선했습니다.

### 🐛 버그 수정 & 성능 개선 (Fixed)
*   **모바일 가로 1줄 배치 및 스택 정렬 최적화 (`responsive.css`)**:
    *   **드롭다운 컴팩트 한 줄 배치**: 모바일 뷰포트에서 소비 분석/수입 탭의 날짜 및 비교기준 선택 드롭다운(`.control-bar`)이 두 줄로 나뉘어 깨지던 문제를 해결하기 위해, 가로 정렬(`flex-direction: row`) 및 셀렉트 박스 폭 축소(`95px` 지정) 최적화 룰을 추가했습니다.
    *   **카드 헤더 세로 스택 전환**: 대시보드의 결제수단 통계 카드 등에서 타이틀과 우측 서브 설명이 가로로 충돌해 깨지는 문제를 막고자, 모바일 뷰포트에서 `.card-header`가 세로 정렬(`flex-direction: column`)로 부드럽게 떨어지도록 변경했습니다. 단, 타이틀이 짧고 더 보기 버튼이 배치된 최근 지출 내역 카드 헤더는 가로 배치 정렬을 그대로 유지하도록 분리 설계했습니다.
    *   **최근 지출 내역 "더 보기" 버튼 축소**: 더 보기 버튼에 오타로 사용되던 `text-sm` 클래스를 아담한 소형 규격인 `btn-sm`으로 교정하여 높이(`32px`)와 패딩을 컴팩트하게 리디자인했습니다.

## [2.2.0] - 2026-06-14

### 🚀 신규 기능 (Added)
*   **HTML/CSS 기반 AI 소비 리포트 시각화 차트 도입**:
    *   AI 소비 리포트 생성 프롬프트에 다크 모드에 최적화된 HTML/CSS 마크업 응답 규칙을 도입했습니다.
    *   수입/지출 비중을 보여주는 반투명 카드 레이아웃, 동적 그라데이션 Progress Bar 게이지 바, 그리고 카테고리별 비중을 가독성 있게 나타내는 conic-gradient 원형(도넛) 차트 시각화 기능을 제공합니다.
    *   프론트엔드 줄 단위 마크다운 파서(`parseMarkdownToHtml`)의 HTML 예외 판단 규칙을 강화하여, 복잡한 인라인 스타일 차트 코드가 문단 태그(`<p>`)로 감싸여 레이아웃이 왜곡되던 문제를 해결했습니다.
    *   AI 모델이 HTML/CSS 마크업 블록을 줄바꿈(`\n`) 없이 단 한 줄의 완성된 텍스트 행(Single Line)으로 출력하도록 프롬프트 제약사항을 추가해 렌더링 안정성을 확보했습니다.
*   **AI 패턴 자동 생성 엔진 고도화**:
    *   AI 패턴 생성의 반환 구조를 단순 정규식 문자열에서 결제수단(`payMethod`), 결제방식(`payType`), 거래유형(`type`)을 포함한 구조화된 `AIPatternResult` 객체 반환 구조로 전면 개편했습니다.
    *   생성 완료 시 규칙 수동 입력 폼에 추출된 값들이 유기적으로 자동 바인딩되어 사용자 편의성을 극대화했습니다.
