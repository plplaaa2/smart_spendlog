# Changelog

본 문서는 Smart Spendlog 가계부 서비스의 공식 버전별 갱신 이력 및 변경 사항을 기록합니다.

## [2.3.0] - 2026-06-15

### 🚀 신규 기능 & UI 개선 (Added)
*   **메인 헤더 반응형 2행 구조 개편**:
    *   기존 단일 행 구조에서 상단 행(글로벌 타이틀 및 알림/사용자 제어)과 하단 행(컨텍스트 정보 및 월간 선택기)으로 분할된 2행 레이아웃을 구현했습니다.
    *   월 선택기(`.month-picker`)가 대시보드 화면에서만 동적으로 노출되도록 렌더러와 탭 전환 이벤트를 보강했습니다.
    *   사이드바 하단 영역의 프로필 및 로그아웃 인터페이스를 헤더 상단의 우측 밀착 영역(`.header-right`)으로 배치 이관하여 공통 정합성을 확보했습니다.
*   **서브 탭 하이라이트 스타일 표준화**:
    *   소비 분석 서브 탭 등에서 존재하지 않는 스타일 변수(`--primary-color`) 사용으로 액티브 하이라이트가 누락되던 버그를 `var(--accent-color)` 공통 변수로 치환 및 인라인 스타일을 배제하여 통일성 있게 표준화했습니다.
    *   '은행별 입출금'을 '은행 입출금'으로, '일반지출 분석/고정지출 분석'을 '일반지출/고정지출'로 서브탭 레이블을 직관적으로 개선했습니다.

### 🐛 버그 수정 & 성능 개선 (Fixed)
*   **모바일 가로 1줄 배치 및 스택 정렬 최적화 (`responsive.css`)**:
    *   **드롭다운 컴팩트 한 줄 배치**: 모바일 뷰포트에서 소비 분석/수입 탭의 날짜 및 비교기준 선택 드롭다운(`.control-bar`)이 두 줄로 나뉘어 깨지던 문제를 해결하기 위해, 가로 정렬(`flex-direction: row`) 및 셀렉트 박스 폭 축소(`95px` 지정) 최적화 룰을 추가했습니다.
    *   **카드 헤더 세로 스택 전환**: 대시보드의 결제수단 통계 카드 등에서 타이틀과 우측 서브 설명이 가로로 충돌해 깨지는 문제를 막고자, 모바일 뷰포트에서 `.card-header`가 세로 정렬(`flex-direction: column`)로 부드럽게 떨어지도록 변경했습니다. 단, 타이틀이 짧고 더 보기 버튼이 배치된 최근 지출 내역 카드 헤더는 가로 배치 정렬을 그대로 유지하도록 분리 설계했습니다.
    *   **최근 지출 내역 "더 보기" 버튼 축소**: 더 보기 버튼에 오타로 사용되던 `text-sm` 클래스를 아담한 소형 규격인 `btn-sm`으로 교정하여 높이(`32px`)와 패딩을 컴팩트하게 리디자인했습니다.

## [2.2.0] - 2026-06-14

### 🚀 신규 기능 (Added)
*   **HTML/CSS 기반 AI 소비 리포트 시각화 차트 도입**:
    *   AI 소비 리포트 생성 프롬프트에 다크 모드에 최적화된 HTML/CSS 마크업 응답 규칙을 도입했습니다.
    *   수입/지출 비중을 보여주는 반투명 카드 레이아웃, 동적 그라데이션 Progress Bar 게이지 바, 그리고 카테고리별 비중을 가독성 있게 나타내는 conic-gradient 원형(도넛) 차트 시각화 기능을 제공합니다.
    *   프론트엔드 줄 단위 마크다운 파서(`parseMarkdownToHtml`)의 HTML 예외 판단 규칙을 강화하여, 복잡한 인라인 스타일 차트 코드가 문단 태그(`<p>`)로 감싸여 레이아웃이 왜곡되던 문제를 해결했습니다.
    *   AI 모델이 HTML/CSS 마크업 블록을 줄바꿈(`\n`) 없이 단 한 줄의 완성된 텍스트 행(Single Line)으로 출력하도록 프롬프트 제약사항을 추가해 렌더링 안정성을 확보했습니다.
*   **AI 패턴 자동 생성 엔진 고도화**:
    *   AI 패턴 생성의 반환 구조를 단순 정규식 문자열에서 결제수단(`payMethod`), 결제방식(`payType`), 거래유형(`type`)을 포함한 구조화된 `AIPatternResult` 객체 반환 구조로 전면 개편했습니다.
    *   생성 완료 시 규칙 수동 입력 폼에 추출된 값들이 유기적으로 자동 바인딩되어 사용자 편의성을 극대화했습니다.
*   **결제수단과 결제방식(신용/체크) 개념의 전면 분리**:
    *   가계부 데이터 추출 가이드 및 파싱 분류 구조에서 결제수단(카드/은행명)과 결제방식(신용/체크/이체 등)을 완전 격리하여 명시적으로 필드를 분리했습니다.
    *   정규식 수동 작성 가이드 UI에도 각각의 Named Capture Group(`(?<payMethod>...)`, `(?<payType>...)`) 규칙을 분리 명기하여 수동 정규식 입력 정확도를 높였습니다.

### 🐛 버그 수정 & 성능 개선 (Fixed)
*   **안드로이드 정규식 컴파일(ICU 언더바 제약) 대응 백엔드 동기화**:
    *   안드로이드 OS의 ICU 정규식 컴파일 엔진에서 Named Capture Group명 내 언더바(`_`) 문자 사용 시 컴파일 예외(`U_REGEX_INVALID_CAPTURE_GROUP_NAME`)를 발생시켜 오작동하던 문제를 우회 처리하기 위한 `sanitizePattern` 정화 필터를 이식했습니다.
    *   이 필터를 Add-on(백엔드)의 파사드(`parser.js`), 파서(`text_parser.js`), 유틸(`utils.js`) 및 라우터(`webhook.js`, `rules.js`) 전 영역에 동기화하여, 저장되어 있는 언더바 포함 정규식과 실시간 검증 기능이 모바일과 웹 환경 전체에서 100% 동일하게 작동하도록 정합성을 갖추었습니다.
*   **AI 리포트 생성 타임아웃 제한 대폭 연장 (180초)**:
    *   정교해진 HTML 시각화 보고서 출력 과정에서 토큰 전송 소요 시간이 늘어나 클라이언트 HTTP 요청이 60초 만에 Abort(단절)되던 성능 보틀넥 문제를 해결하기 위해, 타임아웃 제한을 **180초(3분)**로 대폭 증가시키고 대기 화면 UI 로딩 텍스트를 정밀 보정했습니다.
*   **카테고리 자동 판단 및 순서 개선**:
    *   가계부 카테고리 판단 시 사용자가 수동 설정한 카테고리를 최우선 존중하도록 백엔드 처리 순서를 바로잡았으며, 페이/머니 충전 시 유발되던 불필요하고 모호한 '페이류' 자동 카테고리 분류 Heuristic 로직을 삭제하고 기본 분류 Fallback을 '기타'로 환원하여 통계 신뢰도를 높였습니다.
*   **모바일/태블릿 반응형 대시보드 개선**:
    *   1024px 이하 해상도에서 사이드바가 기본 접히도록 설정하고, 토글 버튼의 크기를 36px로 고정 및 터치 영역을 확장했습니다.
    *   이중 이벤트 바인딩으로 인한 토글 상쇄 버그 방지를 위해 `isAppInitialized` 방어 가드와 400ms 스로틀을 적용하고, 아웃라인 번짐 방지 및 WebView 포커스 이탈 로직(`tabsindex=-1`)을 추가하여 터치 오작동을 근본 해결했습니다.
    *   규칙 추가 모달 가시성 제고를 위해 수동 정규식 조립 가이드를 접이식 아코디언 메뉴로 가볍게 개선했습니다.

## [2.1.0] - 2026-06-05

### 🚀 신규 기능 (Added)
*   **네트워크 자동 백업 기능 추가 및 안정화**:
    *   Samba(SMB/UNC 경로) 및 WebDAV 외부 NAS 원격 저장소로 가계부 백업 데이터(.json)를 자동으로 내보내는 일체형 network 백업 시스템을 탑재했습니다.
    *   설정 화면의 데이터 관리 탭에서 시간 및 요일별 자동 스케줄링 설정을 제공하며, 복사 실패 시 메인 동작에 영향을 미치지 않는 Fail-safe 구조를 갖추었습니다.
    *   백업 파일 전송 시 서버 토큰 기반의 AES-256-CBC 암호화를 지원하여 외부 네트워크 전송 시 보안성을 크게 확보했습니다.
*   **AI 설정 마스터 스위치 및 종속 제어 스위치 분리**:
    *   전반적인 AI 기능 사용 제어를 위한 "AI 기능 활성화" 마스터 스위치(`settings-ai-enabled`)와 알림 문자 분석 실패 시 폴백 파싱을 제어하는 "AI 자동 파싱 활성화" 서브 스위치(`settings-ai-parsing-enabled`)로 이원화하였습니다.
    *   **종속적 UI 제어**: "AI 기능 활성화"가 체크 해제되면 "AI 자동 파싱 활성화" 체크박스는 자동으로 비활성화(disabled) 및 체크 해제(unchecked)되며, 상세 AI API 설정 폼이 보이지 않도록 UI 유기적 반응 제어를 탑재하였습니다.
    *   **API 유효성 검증 강화**:
        *   자동 파싱 웹훅(webhook) 호출 시에는 두 스위치(`ai_enabled` 및 `ai_parsing_enabled`)가 모두 활성화되어 있는 경우에만 AI 파싱을 수행합니다.
        *   수동 AI 패턴 생성 및 AI 소비 리포트 생성 시에는 자동 파싱 토글 여부와 상관없이 마스터 스위치(`ai_enabled`)가 활성화되어 있으면 정상 작동하도록 설계를 세분화하였습니다.
*   **"외식비" 카테고리 명칭 명확화**:
    *   기존 식비 관련 카테고리 명칭(식비, 식비/외식 등)을 보다 직관적이고 표준화된 **'외식비'**로 명칭을 통합 변경하였습니다.

### 🐛 버그 수정 & 성능 개선 (Fixed)
*   **알림 문자 파싱 엔진 고도화**:
    *   문장 내 줄바꿈 문자 처리 방식을 UNIX 형식(`\n`)으로 표준화하여 정규식 규칙 매칭 성능을 개선하고, 휴리스틱 파싱 알고리즘을 개선하여 금액/사용처 오인식을 해소했습니다.

## [2.0.0] - 2026-06-02

### 🚀 신규 기능 (Added)
*   **AI 기반 종합 소비 리포트**:
    *   사용자별 맞춤형 재무 분석을 제공하기 위해 가계 통계 데이터를 기반으로 한 AI 소비 분석 리포트 엔진을 도입했습니다.
    *   **다양한 모델 지원**: Google Gemini, OpenAI 최신 저가 모델 및 로컬 구동 OpenAI 호환 LLM 서버를 연동할 수 있습니다.
    *   **인터랙티브 대시보드**: 가계부 사이드바에 'AI 소비 리포트' 탭을 신설하고, 로딩 및 비활성화 예외 처리, 생성 완료 시 실시간 영구 조회 및 리포트 저장 기능을 구현했습니다.
*   **AI 패턴 자동 생성 엔진**:
    *   정규식 사용에 어려움을 겪는 사용자들을 위해, 알림 로그 문자 내용으로부터 정규식(Named Capture Group)을 자동 생성 및 추천해주는 'AI 패턴 자동 생성' 기능을 규칙 등록 모달에 추가했습니다.

### 🐛 버그 수정 & 성능 개선 (Fixed)
*   **고정지출 분석 카테고리 누락 결함 수정**:
    *   카테고리 개편(공과금 ➔ 수도광열비, 주거/통신 ➔ 주거 & 통신비) 이후 백엔드 고정지출 쿼리 목록에 미반영되어 통계에서 제외되던 결함을 수정했습니다. 이제 '수도광열비', '주거', '통신비'가 고정지출에 올바르게 합산됩니다.
*   **SQLite UNIQUE 제약 조건 NULL 중복으로 인한 연간 리포트 적체 버그 해결**:
    *   연간(`YEARLY`) 리포트를 저장할 때 `target_month` 값을 `NULL` 대신 `0`으로 보정하여 저장 및 조회하도록 개선했습니다. SQLite의 UNIQUE 제약조건에서 `NULL` 중복이 허용되어 리포트 재생성 시 행이 무한히 쌓이고 과거 데이터가 무작위로 호출되던 데이터 정합성 문제를 원천 해결했습니다.
*   **Rate Limiter 리버스 프록시 IP 추출 처리 보완**:
    *   Express 서버에 `trust proxy` 설정을 활성화하고, Home Assistant Ingress 등 외부 프록시 환경에서 `x-forwarded-for` 헤더에 쉼표로 연결된 IP 목록이 전달되더라도 실제 클라이언트 IP만 안전하게 분리 추출하여 Rate Limiting을 적용하도록 보완했습니다.

## [1.1.0] - 2026-05-31

### 🚀 주요 변경 사항 & 신규 기능
*   **로컬/네트워크 백업 및 복원 시스템 전면 개편**:
    *   **JSON 데이터 전환**: SQLite `.db` 파일 직접 복사 백업에서 데이터베이스 테이블을 직렬화한 `.json` 파일 백업 방식으로 전면 교체하여 시스템/환경 간 완벽한 이식성 및 복구 호환성을 확보했습니다.
    *   **AES-256-CBC 암호화**: 개인 가계부 정보 보안 강화를 위해 백업 파일 생성 및 전송 시 서버 비밀 토큰을 기반으로 AES-256-CBC 대칭 암호화가 적용됩니다.
    *   **수동 암호화 백업 선택 기능**: 수동 JSON 백업 내보내기 시 암호화 여부를 선택할 수 있도록 옵션을 제공하여, 타 토큰 환경으로 데이터 이전 시 암호화 해제 후 다운로드/이관이 가능하도록 개선했습니다.
*   **보안 강화 및 계정 보호**:
    *   **로그인 지수 대기 차단 (Exponential Backoff)**: 무차별 대입 공격을 차단하기 위해 로그인 5회 실패 시 실패 횟수에 비례해 잠금 기간 및 리셋 윈도우가 지수적으로 증가(15분 ➔ 30분 ➔ 1시간...)하는 보안 모델을 구현했습니다.
    *   **보안 HTTP 헤더 주입**: 클릭재킹 및 XSS 공격 방지를 위해 CSP, X-Frame-Options 등 OWASP 표준 보안 헤더를 API 미들웨어에 강제 주입했습니다.
    *   **API 속도 제한**: IP 기반의 Rate Limiter를 적용하여 웹훅(분당 10회), 로그인(분당 10회), 일반 API(분당 60회)의 호출 빈도를 정밀 차단/제어합니다.
*   **수입 분석 대시보드 신설 및 분석 고도화**:
    *   **소득 분석(Income Analytics) 메뉴 독립**: 기존 소비 분석 하위 탭에 있던 수입 통계 분석을 1차 메뉴(사이드바 및 모바일 네비게이션)로 분리하고, 모바일 스크롤 및 독립형 연/월 필터를 지원합니다.
    *   **일반/고정지출 연간 전체 분석**: 소비 분석 내 연간(올해 전체) 필터 조회 시 12개월 소비 추이 및 고정지출 항목(공과금, 구독, 보험, 주거/통신, 대출상환)별 추이 분석을 고도로 제공합니다.
*   **앱 패키지명 결제수단 자동 매핑 프리셋**:
    *   **자동 매핑 엔진**: SMS 알림 외에도 주요 은행/카드사/간편결제 앱에서 발송한 푸시 알림 수신 시 발신 앱의 패키지명(Package)에 따라 사전에 정의된 결제수단이 자동 매핑되도록 프리셋 데이터를 구축했습니다.
    *   **패키지 매핑 커스텀 관리**: 사용자가 UI 상에서 직접 패키지명과 결제수단 간 매핑 규칙을 생성, 수정, 삭제할 수 있는 관리 기능을 추가했습니다.
*   **카테고리 고도화 및 정밀 마이그레이션**:
    *   **세분화된 카테고리 지원**: '주유/교통', '공과금', '구독', '보험', '대출상환' 등 고정/변동 지출의 분류 정밀도를 높였으며, DB 시딩 및 기존 데이터를 마이그레이션할 때 UNIQUE 제약조건 위반을 방지하는 안전 병합 로직을 적용했습니다.
    *   **정규식 파서 개선**: 분류 키워드 매칭 시 단어 경계를 정밀 대조(예: '마트' 감지 시 '스마트폰' 등은 예외 처리)하여 오파싱을 획기적으로 낮췄습니다.
*   **카드 결제 및 거래 이중 등록 방지**:
    *   **체크카드 이중 결제 등록 방지**: 체크카드 결제 시 카드 승인 알림(카드사)과 계좌 출금 알림(은행)이 동시에 발생하여 가계부에 지출이 중복 등록되던 문제를 해결했습니다. 30초 이내에 동일한 금액 및 유사한 가맹점으로 발생하는 이종 결제수단 거래를 이중 등록(`IGNORED_DUPLICATE`)으로 감지해 자동으로 차단합니다.
    *   **카드 결제대금 자동 이체 감지 강화**: 카드 결제일 및 청구서 관련 문자 알림 발생 시, 해당 내역을 지출이 아닌 카드 결제대금 납부(자산 이동 또는 이체) 성격으로 판단하여 자산 및 지출 통계 왜곡을 예방하도록 감지 알고리즘을 강화했습니다.
