# Smart Spendlog 사용 안내

## 설치와 접속

애드온을 설치한 뒤 구성에서 인증값과 사용자 계정을 설정하고 시작합니다.
Home Assistant의 **웹 UI 열기** 또는 사이드바를 통해 접속할 수 있습니다.
Ingress 접속에는 호스트의 8124 포트 개방이 필요하지 않습니다.
직접 웹 접속 또는 외부 기기의 웹훅에는 네트워크 탭의 포트 매핑을 사용합니다.

현재 지원 아키텍처는 `amd64`, `aarch64`입니다. 이미지는 설치하는 HA 호스트에서 빌드됩니다.

## 구성 항목

- `token`: 서비스 인증 및 암호화에 사용하는 값입니다. 기존 데이터를 사용하는 경우 임의로 변경하지 마세요.
- `webhook_token`: 웹훅 요청 인증에 사용하는 값입니다.
- `users`: 로그인 계정 목록입니다. 각 항목에 `username`, `password`를 지정합니다.

초기 인증값과 비밀번호는 사용 전에 고유한 값으로 설정하세요.
실제 인증값을 로그나 이슈에 첨부하지 마세요.

## 알림 수집과 데이터

Home Assistant Companion 앱에서 마지막 알림 센서를 활성화하고, 카드·은행 등 필요한 앱만 허용합니다.
Smart Spendlog의 **설정 > 기본 설정**에 알림 센서 Entity ID를 등록합니다.
웹훅 수집과 AI 설정의 상세 절차는 [README](https://github.com/plplaaa2/smart_spendlog/blob/main/account_book/README.md)를 참고하세요.

가계부 데이터와 구성은 영구 저장 영역 `/data`에 보관됩니다.
백업 대상은 HA가 제공하는 `/share`, `/backup`, `/media` 경로 또는 WebDAV를 사용할 수 있습니다.
컨테이너 안에서 Windows UNC 경로를 직접 마운트하는 방식은 지원하지 않습니다.
중요한 변경 전에는 애드온을 중지한 상태에서 HA 백업을 만들고, 앱의 데이터 내보내기도 보관하세요.

## 문제 확인

시작이 실패하면 애드온 로그를 확인합니다. 알림이 들어오지 않으면 센서 ID와 허용 앱 목록을 확인합니다.
웹훅 인증 오류는 요청 인증값과 애드온 구성이 일치하는지 확인합니다.
문제 보고에는 애드온 버전, HA 버전, CPU 아키텍처, 개인정보를 제거한 로그를 포함하세요.
