# 현재 알림(Notifications) 파싱 구조 설명

이 문서는 시스템 내에서 '현재 알림' 데이터를 처리하는 파싱 구조를 설명합니다.

## 1. 데이터 수집 (Data Collection)
시스템은 사용자로부터 들어오는 요청(Request)을 통해 알림 데이터를 수집합니다. 주로 JSON 형식의 페이로드(Payload)를 포함하며, 인증 토큰(`authenticateToken`)을 통해 유효성을 검증합니다.

## 2. 파싱 프로세스 (Parsing Process)
- **JSON 디코딩**: 들어온 요청 데이터는 표준 JSON 라이브러리를 사용하여 객체로 변환됩니다.
- **필드 추출**: 알림 내용(Message), 발송 대상(Recipient), 우선순위(Priority) 등의 핵심 필드를 추출합니다.
- **데이터 정규화**: 파싱된 데이터를 시스템 내부에서 사용하는 표준 포맷으로 매핑합니다.

## 3. 예외 처리 (Exception Handling)
파싱 과정에서 발생할 수 있는 오류를 다음과 같이 처리합니다:
- **잘못된 형식**: JSON 형식이 아닐 경우 `400 Bad Request` 에러를 반환합니다.
- **필드 누락**: 필수 알림 필드가 없을 경우 해당 항목을 무시하거나 기본값을 할당합니다.

## 4. 보안 (Security)
모든 파싱 과정은 암호화된 데이터를 다루기 전, `crypto_helper.js`를 통해 데이터의 무결성을 확인하는 단계를 거칩니다.
