# Smart Spendlog 문서

이 문서 영역은 Add-on과 향후 Android 애플리케이션이 공유할 수 있는 프로젝트 기준 문서를 관리한다.

## 현재 문서 범위

- `SYSTEM_ARCHITECTURE.md`: 전체 시스템 경계와 데이터 흐름
- `ADDON_MESSAGE_PARSING.md`: 알림 파싱 규칙과 필드별 세부 명세
- `ADDON_FRONTEND.md`: Home Assistant Add-on 웹 프론트엔드
- `ADDON_BACKEND.md`: Add-on Node.js 백엔드와 데이터 계층

Android 애플리케이션은 기존 산출물을 이어서 복구하지 않고, 별도 설계로 새로 개발한다. 따라서 현재 문서에서는 Android의 구현 세부사항을 정의하지 않는다.
